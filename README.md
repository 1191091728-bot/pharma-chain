## 🎯 项目简介

药链通是医药多智能体助手的"国创赛扩展版"——把 AB 跨域三智能体扩展到 **处方药 + 美妆品** 双品类，加上 **区块链溯源底座**，目标是把"查询是否可信"延展到"商品流通是否可信"。

一个从 PRD 到产业级方案的演化：**从"医生敢用 AI"，到"消费者敢买药"。**

### ✨ 设计要点

* 🌏 **AB 跨域三智能体**：国内 A 域 + 国外 B 域 + 综合裁决 C
* 🔗 **区块链溯源**：商品流通全链路可信
* 💊 **双品类覆盖**：处方药 + 美妆品安全电商场景
